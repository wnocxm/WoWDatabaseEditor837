# TrinityCore BfA 8.3.7 support

Core version: **TrinityCore BfA 8.3.7** (tag `TrinityBfa`, game version 8.3.7.35662).

Pick it in *Settings → Core version*, then set the world/auth database connection as usual.
The reference schema is TrinityCore `TDB837.20101` (see `docs/tc837-schema`).

## What is covered

- Database provider (`TrinityBfaMySqlDatabaseProvider`) written against the 8.3.7 world schema:
  - `creature_template` with `minlevel`/`maxlevel`, `difficulty_entry_1-3`, `lootid`, `HealthModifier`, `InhabitType`
    and models from `creature_template_model`
  - `creature.spawndist`, `creature_addon`/`creature_template_addon` with `bytes1`/`bytes2`
  - `smart_scripts` with `event_param1-5` and `action_param1-6` (no `Difficulties` column)
  - `conditions` without `ConditionStringValue1`
  - `gossip_menu_option` + `gossip_menu_option_action` + `gossip_menu_option_box`
  - `waypoint_data`, `waypoints` (no orientation/delay), `script_waypoint`
  - loot tables with the `Reference` column
  - `event_scripts`, `spell_scripts`, `waypoint_scripts` (no comment column)
- Table editor definitions: 113 tables enabled for `TrinityBfa`. Tables whose 8.3.7 layout differs
  have their own definition in `WDE.DatabaseEditors/DbDefinitions/bfa`.
- SmartAI events/actions/targets and conditions matched against 8.3.7 `SmartScriptMgr.h` and `ConditionMgr.h`.
- Query generators: spawns, gossip, npc_text, loot, quests, spawn groups.

## Hotfixes database

Fill the *Hotfix database* connection in the database settings (for example `hotfixes`).

- `broadcast_text` / `broadcast_text_locale` are read from it, so broadcast text pickers and names work.
  If it is not configured, broadcast texts are simply empty.
- All 324 tables of the 8.3.7 hotfixes schema can be opened in the table editor (group *Hotfixes*,
  definitions in `WDE.DatabaseEditors/DbDefinitions/bfa_hotfixes`).
- The client only receives a changed hotfix row when `hotfix_data` has a matching entry
  (`Id`, `TableHash` of the DB2, `RecordId`); add it yourself after editing.

## DBC settings

Pick DBC version **BFA_35662** and point the path to the extracted DB2 folder of the server
(for TrinityCore: `dbc/enUS`). The DB2 column layout is resolved by DBCD from WoWDBDefs
(downloaded on first start, then cached). The editor checks that spell 1 is named "Word of Recall (OLD)".

## Client data files (game folder)

8.x clients use `World of Warcraft/_retail_/Wow.exe` with the data in `World of Warcraft/Data`.
Both `World of Warcraft` and `_retail_` can be selected. The 3D map/model preview does not support
8.x client files yet, so this setting is optional and not needed for database editing.

## Not available in 8.3.7 (disabled)

- `npc_text` editing helpers (8.3.7 uses BroadcastTextID0-7 columns; the table editor still works)
- `creature_template_difficulty`, `creature_template_gossip`, `serverside_spell`, `phase_name`,
  `areatrigger_create_properties`
- `creature_classlevelstats` stats helper (8.3.7 table has no base hp/damage columns)
- Packet viewer waypoint export to `waypoints`

## Custom BfA cores

Private BfA cores often add or rename columns. If a table fails to open, compare it with
`mysqldump --no-data world` of your database and adjust the matching file in
`WDE.DatabaseEditors/DbDefinitions/bfa` (or the model in
`WoWDatabaseEditor.Common/WDE.TrinityMySqlDatabase/Models/BfaModels.cs`).
